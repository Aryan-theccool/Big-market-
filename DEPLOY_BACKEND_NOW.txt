================================================================================
                        STEP 1: OPEN RENDER
================================================================================

Click this link (or copy-paste into browser):

    https://dashboard.render.com

You'll see the Render dashboard.

================================================================================
                        STEP 2: CREATE NEW SERVICE
================================================================================

Look for the BLUE "+ New" button (top right area)

Click it → Select "Web Service"

================================================================================
                        STEP 3: CONNECT GITHUB
================================================================================

You'll see: "Deploy your code"

Select: "Build and deploy from a Git repository"

Click "Connect your GitHub account" (if needed)

Select your repository: Big-market-

Branch: main

================================================================================
                        STEP 4: ENTER SERVICE NAME
================================================================================

You'll see a form. Fill in exactly:

┌─────────────────────────────────────┐
│ Service Name: inkspace-backend      │
└─────────────────────────────────────┘

================================================================================
                        STEP 5: SELECT ENVIRONMENT
================================================================================

Look for "Environment" dropdown

Select: Node

================================================================================
                        STEP 6: SELECT REGION
================================================================================

Look for "Region" dropdown

Select: Oregon (us-west)

================================================================================
                        STEP 7: ENTER BUILD COMMAND
================================================================================

Look for "Build Command" field

Enter exactly:

    npm install

================================================================================
                        STEP 8: ENTER START COMMAND
================================================================================

Look for "Start Command" field

Enter exactly:

    npm start

================================================================================
                        STEP 9: SELECT PLAN
================================================================================

Choose "Free" (or "Starter" if you want always-on)

Free is fine for now.

================================================================================
                        STEP 10: ADD ENV VARIABLES
================================================================================

Look for "Environment Variables" section

Click "+ Add" and add these TWO variables:

FIRST VARIABLE:
    Key:   NODE_ENV
    Value: production
    [Add]

SECOND VARIABLE:
    Key:   PORT
    Value: 3000
    [Add]

================================================================================
                        STEP 11: CREATE WEB SERVICE
================================================================================

Scroll down and find the big BLUE button:

    [Create Web Service]

CLICK IT! ✨

================================================================================
                        ⏳ DEPLOYMENT IN PROGRESS
================================================================================

Render will now:

    🔄 Clone your GitHub repository
    📦 Install npm dependencies
    🔨 Build your application
    ✅ Start your server
    🌐 Assign a live URL

This takes 5-10 minutes.

You'll see messages like:
    
    Cloning repository...
    Installing dependencies...
    Building...
    Build succeeded ✓
    Live!

JUST WAIT. Don't close the page.

================================================================================
                        📝 COPY YOUR BACKEND URL
================================================================================

Once it shows "Live" in GREEN, you'll see your URL:

    https://your-service-name.onrender.com

COPY THIS URL! 👈 You need it!

================================================================================
                        🔗 CONNECT TO FRONTEND
================================================================================

Now update your frontend on Vercel:

1. Open: https://vercel.com/dashboard

2. Click on "task" project

3. Go to: Settings → Environment Variables

4. Add/Update these (replace YOUR-URL with your actual Render URL):

    Name: NEXT_PUBLIC_API_URL
    Value: https://YOUR-URL.onrender.com
    
    Name: NEXT_PUBLIC_WEBSOCKET_URL
    Value: wss://YOUR-URL.onrender.com
    
    Name: NODE_ENV
    Value: production

5. Click "Save"

6. Vercel will automatically redeploy ✅

================================================================================
                        ✅ TEST YOUR APP
================================================================================

Wait 2 minutes for Vercel to redeploy.

Then test:

1. Open: https://task-eight-psi-64.vercel.app

2. Click "Start Creating"

3. Create a new board

4. Open the SAME board in another browser tab

5. Draw or add something in one tab

6. It should appear INSTANTLY in the other tab

If it appears instantly → ✅ SUCCESS! Everything works!
